# Agent prose carries no numbers; figures come from cited Signals

The Planning Analyst Agent's findings and Hypothesis Verdicts must cite Signal ids, and a validator rejects prose that contains numbers, investment-advice wording or unknown Signal ids. The page shows values from the cited Signals, so the LLM is never a source of market data. The agent gets one repair attempt; if it still fails, a labelled Host Fallback is shown instead. We accept stiffer prose in return for a guarantee that every figure traces to a deterministic computation over the Sectors Snapshot.
