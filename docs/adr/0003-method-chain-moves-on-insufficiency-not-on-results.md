# The Method Chain moves on insufficiency, never on an unwelcome result

The order of valuation methods is fixed from the Method Gate verdicts before any value is computed. A method is skipped only when it is Insufficient: a required input is missing or a structural check fails. When the first sufficient method gives an extreme result (upside above +100% or downside below -50%), the chain stops there and the Company Update stays a Draft with a Review Required rating until a sourced fundamental thesis exists. Moving on to a method with a more comfortable number would be method shopping. One module holds these thresholds (Method Gate 5) and is shared by the chain, the Stage Checks and the spec so they cannot drift apart.

## Consequences

Sufficient methods that are not selected appear only as cross-checks and are never averaged into the Target Price.
