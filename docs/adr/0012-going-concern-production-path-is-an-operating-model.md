# The going-concern production path is an operating model

A going-concern forecast is Production-Ready only when it comes from a sourced operating driver file (`data/operating_drivers/<TICKER>.json`) that `app.operating_model` projects into five years of segment volume x realized price, per-unit and fixed costs, depreciation on opening net PP&E, committed and sustaining capex, working capital in days, fixed-rate debt and dividends, with the FCFF identity, the balance sheet and non-negative liquidity reconciled every year and the first half equal to the official actual. The DCF values that model's own FCFF (not intensities re-derived from history); contracts that end drop out of the terminal line; the terminal passes its per-run economics check; `app.reference_fcff` recomputes the value per share independently within 0.5%; and the house policy must be effective on the Report Date. Forward drivers may be labelled Analyst Assumptions with a rationale and sourced basis. The report keeps the scenario layout the value was built on and shows only the release status as Production-Ready. We chose a per-issuer driver file over a shared industry template because issuers' revenue drivers differ, and shared code must hold no issuer values.
