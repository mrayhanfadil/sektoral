# Terminal economics are checked per run and labelled

The house assumption set (policy 1.1.0) records each discount-rate and terminal-growth parameter with its currency, tenor, nominal basis, policy or observation kind, review range, dated benchmark and rationale; an issuer-specific deviation is not supported and fails closed. Whether a perpetuity is economically consistent depends on the issuer's own forecast, so it is checked on every run against the selected valuation rather than asserted in the policy: an FCFF terminal must reinvest to grow and may not earn more on new capital than the explicit forecast earns on its capital, a bank's terminal growth may not exceed retained earnings times terminal ROE, and terminal growth stays below the discount rate, the nominal risk-free rate and dated long-run nominal GDP growth in the cash-flow currency. A failed check labels the method and blocks only a Production-Ready path, consistent with "label first, withdraw when material" (release policy 1.2.0); restating the terminal at the ceiling return is an open policy decision, and each failed check reports the per-share effect that restatement would have.
